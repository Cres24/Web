XAMPP Installation & Hello World Execution

Step 1: Download XAMPP

Downloaded XAMPP from the official Apache Friends website.

Step 2: Start Apache & MySQL

Opened XAMPP Control Panel and started Apache and MySQL.

Both services are running (green).

Step 3: Open htdocs Folder

Navigated to C:\xampp\htdocs where all local projects are stored.

Step 4: Create PHP File

Created hello.php inside htdocs using VS Code.

<?php
echo "Hello, World!";
?>

Step 5: Run in Browser

Opened browser and ran:

http://localhost/hello.php

Output: Hello, World!

Successfully executed PHP using XAMPP 🎉
